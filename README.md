# Sudoku Premium

A premium, mobile-first Sudoku game built with React and Vite.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Current features

- Responsive dark premium interface
- Randomized Sudoku boards with four difficulty levels
- Number entry, pencil notes, erase, hints and pause
- Timer, mistake counter, completion state
- No backend or Telegram authentication connected yet
